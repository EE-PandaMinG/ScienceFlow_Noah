## 已知诊断记录

第一次启动未进入任务阶段，vLLM 返回 `System message must be at the beginning`。
失败现场被保留为：

```text
workspaces/manual_circle_packing_example/example-circle-packing/circle-packing_failed_system_message
circle_packing_baseline_launcher_failed_system_message.log
```

根因是 ScienceFlow 的 stable/runtime prompt 有意分成两个连续 system message，而该
vLLM chat template 只接受一条开头 system message。修复默认关闭，仅对本地配置显式
开启；prompt 文本和顺序不变。真实双 system 请求 smoke test 成功，相关单测 71 项通过。

## 重构验收下限

DeepCraft/ScienceFlow 拆分后的 Circle Packing 回归至少必须满足：

1. 相同 worker 配置均正常退出且最终 artifact 通过任务 evaluator。
2. 旧 runtime 路径的 Prompt、Tool Schema、消息顺序、调用时机和 workspace 文件不变。
3. Contract manifest 的路径与格式契约无缺失；只允许登记字段发生易变值变化。
4. 单 worker 最终指标不得低于 `2.1938`，双 worker 最终指标不得低于
   `2.441894866277423`。考虑模型随机性时需补充重复样本，不能用偶然改善掩盖回归。
5. 旧 workspace 必须可以 Resume；Merge 仍选择有效的全局最佳候选。
